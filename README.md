# 上岸 Ashore

每個申請計劃（實習、管培、校園徵才、獎學金、交換、升學…）只有**一個入口**，把投遞後的測驗、面試、錄取通知彙整成清楚的**時間線**，並用**種子**鼓勵大家回報進度。

## 解決什麼問題

| 痛點 | 做法 |
| --- | --- |
| 同一個計劃在 Dcard 開了很多串、關鍵字不統一 | 計劃有**別名**（「中信學期實習」＝「中信 Rising Star」），搜尋任何叫法都導到同一頁；建立前檢查重複 |
| 一堆人問「你是哪一組？」 | 每則回報與提問都**必須選組別／職缺** |
| 留言「卡」佔版面、分不出誰真的有消息 | 改成「追蹤」按鈕＋站內新進度提示；太短的提問會被拒絕 |
| 下一屆不知道通知大概什麼時候來 | 時間線彙整各階段最早／最晚／**中位數**，並有**去年同期**與**歷屆對照** |
| 問了沒人答、原 po 不回 | **種子懸賞**：提問先託管，被採納才付；逾期有人答自動付給最早回答者，沒人答退回 |

## 核心概念

- **計劃（Program）**：只能由使用者建立。名稱／別名正規化後完全相同者不能建立；相似者需勾選確認。建立者有種子獎勵。
- **屆次（Cycle）**：例如「2027 暑期」。可以**複製（fork）**任何一屆成新一屆：沿用組別、記錄 `forked_from`，歷屆串成一條線可以對照。
- **回報（Report）**：階段＋組別＋日期（收到通知那天）。同人同屆同階段只領一次種子；3 位使用者舉報會自動隱藏並收回獎勵。
- **種子（Seeds）**：賺取與花費規則集中在 `src/config.js` 的 `SEEDS`，站上 `/rules` 讀同一份。`users.seeds` 永遠等於 `seed_ledger` 加總（有測試保證）。

## 開發

需求：Node.js ≥ 22.13（使用內建 `node:sqlite`，不需編譯原生套件）。

```bash
npm install
npm start               # http://localhost:3000
npm test                # 端到端測試（記憶體資料庫）

# 想先看版面：產生【示範】資料（內容為虛構）
DATA_DIR=./data-demo npm run seed:demo
DATA_DIR=./data-demo npm start      # 帳號 示範同學1…24 / 密碼 demo-password
```

網站一開始**沒有任何計劃**，全部由使用者建立。

## 部署

單一程序＋單一 SQLite 檔，把 `DATA_DIR` 指到持久化磁碟即可。

```bash
docker build -t ashore .
docker run -p 3000:3000 -v intern-data:/data ashore
```

| 環境變數 | 說明 |
| --- | --- |
| `PORT` | 預設 3000 |
| `DATA_DIR` | 資料庫與 session 密鑰所在目錄，預設 `./data`（`:memory:` 僅供測試） |
| `SESSION_SECRET` | CSRF 簽章密鑰；未設定時會產生並存在 `DATA_DIR/secret` |
| `TRUST_PROXY=1` | 在反向代理後面時開啟（限流才會用到真實 IP） |
| `COOKIE_SECURE=1` | 走 HTTPS 時開啟 |

## 目前的取捨與待辦

- 帳號只有暱稱＋密碼，**不需要 Email，也無法找回密碼**；之後可加學校信箱驗證以降低多帳號刷種子。
- 限流在記憶體內，只適用單機；多機部署需改共用儲存。
- 還沒有管理後台（合併重複計劃、處理檢舉）；目前只有「3 人舉報自動隱藏」。
- 沒有 Email／推播通知，追蹤只在站內顯示。
- 所有時程皆為使用者回報，僅供參考。
